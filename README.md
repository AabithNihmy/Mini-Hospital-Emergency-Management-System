## 📌 Project Description

This project is a Java-based Mini Hospital Emergency Management System. It demonstrates how different data structures can be used to manage hospital patient information and emergency activities.

## 🧩 Data Structures Used

### 1. Binary Search Tree (BST)

Used to manage patient records.

Operations:

* Add patient
* Search patient by ID
* Delete patient
* Display patients using in-order traversal

### 2. Queue

Used to manage patients waiting for emergency treatment.

Operations:

* Enqueue patient
* Dequeue patient
* Display waiting patients
* Handle empty queue

The queue follows **FIFO (First In, First Out)**.

### 3. Stack

Used to store treatment history.

Operations:

* Add treatment record
* Remove latest treatment
* Display treatment history
* Handle empty stack

The stack follows **LIFO (Last In, First Out)**.

### 4. Singly Linked List

Used to maintain patient visit history.

Operations:

* Add visit
* Search visit
* Remove visit
* Display visit history
